# Information Security Quick Reference

Document ID: DOC-004  
Policy owner: Information Security  
Effective date: January 15, 2026  
Status: Active

## Suspected Phishing Messages

If a message appears suspicious, do not click links, open attachments, reply to the
sender, or forward the message to coworkers.

Use the Report Phishing button in the company email application. If that button is not
available, contact the Security Operations Center through the approved internal support
portal.

## Accidental Interaction

If you clicked a suspicious link, opened an attachment, entered credentials, or
approved an unexpected multifactor-authentication request, disconnect from the network
when practical and contact the Security Operations Center immediately.

Do not attempt to investigate the message yourself.

## Passwords and Authentication

Use a unique company password and multifactor authentication. Never approve an
authentication request that you did not initiate.

Information Security will never ask an employee to disclose a password through email
or chat.

## Sensitive Information

Restricted information must be stored only in approved company systems. Employees must
not upload company information to personal cloud storage or unapproved AI services.
